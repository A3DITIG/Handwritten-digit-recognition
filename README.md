# Handwritten-text-recognition

Handwritten Text Recognition using Deep Learning and OCR

Developed an OCR system to extract handwritten text from images using state-of-the-art deep learning models such as TrOCR, EasyOCR, and PaddleOCR. Implemented image preprocessing, text detection, and text recognition pipelines to improve accuracy on handwritten documents. Compared multiple OCR frameworks and visualized detected text regions using bounding boxes.
